# docs

- `architecture.md`: the architecture document and the source of truth until `spec.md` exists. Exported from the live Claude Docs page, which is retired; edit here.
- `user-stories.md`: one story per screen element or contract behaviour, with acceptance and milestone.
- `vocabulary.md`: canonical names and enums; a test checks the `ship/contract` enums against it.
- `decisions-m0.md`, `decisions-m1.md`: binding answers to each milestone's design questions.
- `licenses.md`: the project license, third-party dependency licenses and the CI license check.
- `kickoff-m0.md`, `kickoff-m1.md`: the prompts that start each milestone's Claude Code sessions.
- `reviews/`: independent blind reviews of the architecture, kept for the record.
- `design/`: the Claude Design artboards for the four screens (Design Component pages mounting the Mycroft design system). Reference only; the React bridge is built from the stories, not from these files.
